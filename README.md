# Dreamflect

> A dream-reflection app where the agent renders every screen — and remembers every dream.

Started as a 6-hour Generative UI Hackathon entry (track: *No Designer, No Problem*). Now a working app with auth, persistent memory, an evening reflection loop, voice capture, and AI-generated dream imagery.

## What it is

Sign up. Type or speak your dream. From that moment forward, every screen is chosen by Claude Opus 4.7:

1. **Gap-fill** — Claude reads the dream, picks what's missing (scene without feeling? feeling without scene?), and calls `propose_gap_fill` with a question + chip options.
2. **Archetype** — Names a dream archetype based on dream + gap-fill answer. `propose_archetype`.
3. **Probe** — The unlock-question, archetype-specific (chase → agency, falling → impact/witness). `propose_probe`.
4. **Interpret** — A frame, not a verdict. Quote + expansion. `propose_interpretation`.
5. **Takeaway** — One portable question to carry through the day. `emit_takeaway` includes **A2UI v0.9 messages** (createSurface → updateComponents → updateDataModel) that the client renders via `@a2ui/react`. There's no React component for "the takeaway" — only a renderer for whatever A2UI describes.

The morning ends with a saved session, a downloadable wallpaper PNG generated by gpt-image-1, and an evening-reflection prompt the agent runs against the same memory.

## Features

| Feature | What it does |
|---|---|
| **Memory** | Every completed session is saved to Postgres. The next session's system prompt includes the last 5 archetypes + takeaways so Claude can notice "this is the third chase dream this month — the agency variable keeps shifting." |
| **Visible /history** | A page listing every prior takeaway with date + archetype. Memory becomes tangible. |
| **Evening reflection** | A second flow (`/?mode=evening`) that references the morning's takeaway and asks "did anything today rhyme?" Same agent, different system prompt. Triggered manually via a "preview evening" button. |
| **Voice capture** | Real Whisper transcription. Tap mic → record audio (any browser via `MediaRecorder`) → POST to `/api/transcribe` → Whisper returns text → user edits → submits. Falls back to text-only if `OPENAI_API_KEY` is missing. |
| **Share-as-image** | When a session is saved, gpt-image-1 generates an atmospheric dream artifact in the background (~15s). Two share routes (`/api/takeaway-og/{portrait,square}/[id]`) overlay the takeaway question in Fraunces italic on top of the AI image using `next/og`. Wallpaper format (1170×2632) + social square (1200×1200). Falls back to a typography-only gradient if image gen fails or the key's missing. |
| **Auth** | Better Auth with email + password, custom Dreamflect-styled signin/signup. No social, no magic links — direct path to the dream. |

## Stack

- **Next.js 15** App Router + TypeScript
- **Tailwind v4** + **shadcn/ui** (hand-written primitives, Dreamflect OKLCH palette)
- **CopilotKit v2** (headless `useAgent` + `useFrontendTool`, multi-endpoint `[[...path]]` runtime)
- **A2UI v0.9** (`@a2ui/web_core` + `@a2ui/react`)
- **Better Auth** (email+password, `pg.Pool` adapter against Neon)
- **Neon Postgres** via `@neondatabase/serverless` (HTTP, edge-friendly)
- **Anthropic Claude Opus 4.7** via CopilotKit's `BuiltInAgent({ model: "anthropic:claude-opus-4-7" })`
- **OpenAI** Whisper (transcription) + gpt-image-1 (dream art)

## Architecture

```
Browser                                 Next.js                              External
─────────                               ──────────                           ─────────
Providers (mode: morning|evening)  ──▶  /api/copilotkit/[[...path]]   ──▶   Anthropic Opus 4.7
   │                                       │ (per-request)
   │                                       │   - reads session cookie (Better Auth)
   ├─ useFrontendTool ×5 (gap-fill,        │   - reads ?mode= query
   │   archetype, probe, interpret,        │   - fetches prior sessions from Neon
   │   takeaway)                           │   - buildSystemPrompt({mode, priorSessions, latestMorning})
   │                                       │   - new BuiltInAgent + CopilotRuntime per request
   ├─ useAgent.addMessage / runAgent
   └─ takeaway commit triggers:
       └─ POST /api/sessions ───────▶    saveSession (Neon)
                                            └─ fire-and-forget gpt-image-1 ──▶ OpenAI
                                                 └─ writes image_b64 to row

CaptureStep mic button:
   └─ MediaRecorder → POST /api/transcribe ──▶ OpenAI Whisper

Takeaway screen share buttons:
   └─ /api/takeaway-og/{portrait,square}/[id] (edge runtime)
        └─ reads image_b64 + takeaway from Neon (HTTP driver)
        └─ overlays Fraunces italic via next/og ImageResponse

/history (server component) ──▶ getAllSessions(userId) ──▶ Neon
```

## Run it

```bash
# Use pnpm — npm conflicts with the existing pnpm-lock.yaml.
pnpm install

# Configure env (see .env.local.example)
# Required: ANTHROPIC_API_KEY, DATABASE_URL, BETTER_AUTH_SECRET, BETTER_AUTH_URL
# Optional: OPENAI_API_KEY (enables voice + AI dream images)
cp .env.local.example .env.local
# generate a secret:
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# Apply schema once (Better Auth tables + dream_sessions)
# — see scripts/ or apply via Neon MCP / psql
# — Better Auth schema can be generated with: npx @better-auth/cli generate

pnpm dev
# → http://localhost:3000
```

`pnpm` is required because we use `node-linker=hoisted` in `.npmrc` so Next.js can resolve `@tailwindcss/postcss` and `@swc/helpers` without isolated-module weirdness.

## Demo script (≤ 3 min)

1. Sign up (email + password), land on the dream session.
2. Click the mic, speak a dream out loud, click stop. Whisper transcribes (~3-5s). Edit, submit.
3. Click through the 5 generated steps. Notice: the gap-fill question, archetype, and probe are all picked from your specific dream.
4. The takeaway is rendered via the A2UI protocol (the agent emits JSON describing a `Column` with two `Text` nodes; the client renders it).
5. Click "wallpaper" — wait ~10s if the gpt-image-1 generation hasn't finished — download a 1170×2632 PNG with the AI dream art as background and your takeaway question in Fraunces italic.
6. Click "preview evening reflection" → land on `/?mode=evening`. The agent's first move references the morning's takeaway question.
7. Click "history" in the sidebar — see your morning + evening sessions listed by date.

## Risks / known limitations

- **Voice + AI image require `OPENAI_API_KEY`.** Without it, voice falls back to text-only and shared images use a typography-only gradient. The app still works.
- **GPT Image latency (~15s).** Hidden by generating server-side at save-time; the share button polls `/api/sessions/[id]/status` and only enables when ready.
- **GPT Image storage.** ~1.5MB base64 per session in Postgres. At scale, move to Vercel Blob or S3.
- **Web Speech API not used** — Whisper is browser-agnostic and more accurate.
- **Single user model.** No org accounts, no shared dreams.
- **Evening reflection is manual-trigger.** No real push notifications.
